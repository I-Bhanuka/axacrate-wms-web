# WMS Frontend

React + TypeScript frontend for Warehouse Management System.

## Tech Stack
- React 18
- TypeScript
- Vite
- React Router
- Axios
- Material-UI / Tailwind CSS
- Recharts

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Setup
1. Clone repository
2. Copy `.env.example` to `.env.development`
3. Run: `npm install`
4. Run: `npm run dev`
5. Open: http://localhost:5173

### Project Structure
- `/src/components` - Reusable UI components
- `/src/pages` - Page components
- `/src/services` - API integration
- `/src/hooks` - Custom React hooks
- `/src/types` - TypeScript type definitions
